# SPX 0DTE 日内蒙特卡洛模拟器技术报告

> 本文说明这套模拟器是什么、为什么选这些模型，以及 smile（波动率微笑）与 VIX 如何逐条路径地影响模拟行情。下图全部由模拟器自身的模型代码生成，标定于仓库自带的 1 分钟 SPX 数据（`tests/fixtures/SPX_1min_10d.csv`）。图注里的数字取自实际输出，不是示意图。

---

## 1. 模拟器在做什么

对 0DTE bull put 价差来说，日度蒙特卡洛没有意义。决定这笔交易成败的是日内结构：theta 与 gamma 的赛跑、U 型波动、崩盘聚集，而不是单一的到期价格。所以模拟器从标定好的波动率模型生成 N 条日内 SPX 路径，每根 bar 在一条与波动率联动的隐含波动率微笑下对价差做市值盯市（mark-to-market），再用与实盘引擎相同的策略定义（入场条件、按 tick 成交、止损 / 止盈 / 到期）判定，最后输出当日 PnL 分布与尾部风险。

<figure>
  <img src="figures/zh/fig01_pipeline.png" alt="端到端模拟器管线">
  <figcaption><b>图 1.</b> 整体管线。三个内部模型（GJR-GARCH 管收益、SVI 管微笑、BSM 管期权价值）彼此独立，只在逐 bar 定价那一处相遇。有两处让世界变得路径依赖：路径生成里的 ATM-IV 波动率上限，以及定价一侧的 smile/VIX 响应。</figcaption>
</figure>

设计上这是个测试台，要求既忠实于实盘又不夸大结论，不是研究用的玩具。

它不发明策略语义。每条入场条件与出场规则都从 `config/strategies.json` 读取，用与实盘 `strategy_engine` 相同的默认值求值。模拟器无法忠实求值的门槛（如 `trend`、`atm_iv`）会被直接拒绝，不会静默跳过。

动力学只用闭式（closed-form）。SVI 在离线状态下拟合一次，运行期绝不重新拟合；路径依赖的响应是叠加在已捕获快照之上的闭式 level/tilt。

引擎只读取 `Strategy` 对象，不下单，也不触碰实盘状态。

## 2. 模型一：带 Student-t 扰动的 GJR-GARCH(1,1)

收益过程用的是 GJR-GARCH(1,1)（Glosten–Jagannathan–Runkle，GARCH 的非对称推广），扰动项服从 Student-t 分布：

```
σ²_t = ω + α·ε²_{t−1} + γ·ε²_{t−1}·1[ε_{t−1} < 0] + β·σ²_{t−1}     （波动率）
ε_t  = σ_t · u(分钟) · z_t ,   z ~ 标准化 t(ν)                       （收益）
```

### 2.1 拟合（方差目标 + MLE）

五个参数 `(ω, α, γ, β, ν)` 用 `scipy.optimize.minimize` 做最大似然估计（Nelder–Mead，以 `ν ∈ {ν₀, 4, 10}` 作多重初值，再精修两次）。目标函数带两条结构性约束：

- 平稳性：`α + γ/2 + β < 1`，否则方差路径会爆炸。
- 方差目标：`ω = σ̄²·(1 − α − γ/2 − β)`，让模型的无条件方差等于去均值对数收益的样本方差。

退化情形有两条保护。MLE 不收敛时回退到预设值 `(α=0.04, γ=0.10, β=0.85, ν=6.0)`，并在 UI 中标记出来。若收益序列的方差为零或恒定，则直接短路到方差目标预设，因为此时 Student-t 似然本身退化，Nelder–Mead 可能"收敛"到一个无意义的内部点而不报错。

### 2.2 杠杆效应（非对称性）

`γ > 0` 意味着负收益会让下一根 bar 的方差上升 `(α+γ)·ε²`，正收益只上升 `α·ε²`。同样幅度的冲击，下跌比上涨更能推高波动率，这就是新闻冲击不对称。

<figure>
  <img src="figures/zh/fig02_gjr_news_impact.png" alt="GJR 新闻冲击不对称">
  <figcaption><b>图 2.</b> 在无条件状态下，单步方差增量对冲击 ε 的响应。响应在 ε=0 处折拐：下跌侧用 `α+γ`，上涨侧用 `α`。压力旋钮 `gamma_mult` 放大 γ（虚线）以增强崩盘聚集。（在这份较平静的数据上拟合出的 γ 偏小，所以折拐较缓。）</figcaption>
</figure>

### 2.3 Student-t 扰动

实证股票收益的尾部比高斯厚。扰动服从自由度为 `ν` 的 Student-t，再做方差标准化（除以 `√(ν/(ν−2))`），使 `E[z²] = 1`，收益尺度仍然可解释。模型要求 `ν > 2`，否则方差无限。

<figure>
  <img src="figures/zh/fig03_student_t.png" alt="Student-t 与正态密度">
  <figcaption><b>图 3.</b> 标准化 Student-t（单位方差）对比 N(0,1)，对数轴。尾部按 `|z|^-(ν+1)` 衰减，而不是 `e^{−z²/2}`，大幅冲击的概率高得多，崩盘聚集与低 ν 压力旋钮都来源于此。ν 越小尾部越厚（`nu_override` 压力旋钮）。</figcaption>
</figure>

### 2.4 日内 U 型波动率

SPX 日内波动率不平坦：开盘高，上午衰减，午间触底，临近收盘抬升。这里用一条非参数乘性剖面 `u(分钟)` 来刻画，由每个分钟桶的标准化平均 `|ε|` 估计后平滑，不需要预设任何函数形式。

<figure>
  <img src="figures/zh/fig04_ushape.png" alt="日内 U 型波动率剖面">
  <figcaption><b>图 4.</b> 由 1m 数据标定出的 U 型。均值 1.0（只对拟合出的波动率做相对缩放），截断于 `[0.25, 4.0]`。应用方式为 `σ_t = √σ²_t · u(t)`。开盘尖峰与收盘抬升正是 0DTE 价差需要日内模拟而非日度模拟的原因。</figcaption>
</figure>

### 2.5 近积分棘轮与 ATM-IV 上限

这是最重要的建模细节之一，和 Student-t 没有关系。在平静数据上拟合出的 GARCH 可能接近积分：`α + γ/2 + β ≈ 0.99`（本数据是 0.9895）。此时条件方差有一个厚尾的平稳分布，于是一小部分模拟路径会把波动率状态棘轮式地推到拟合值 `σ₀` 的 5–10 倍。扇形的中心（p25–p75）其实已经接近市场水平，病态的只是尾部：1 天 p0 能到 −25% 甚至更糟，这里直接冲进 ±50% 的现货保护带。试过两条路都没用：换成正态扰动，问题照旧；整体缩放波动率水平，会被同一棘轮放大成 NaN。

正确的做法是给单根 bar 的 sigma 设上限，而不是改水平：

```
σ_t = min( √σ²_t · u(t),  vol_cap_mult · (atm_iv / √252) / √steps )
```

把 `atm_iv` 设为市场当前的 ATM IV（年化小数），`vol_cap_mult` 默认 2.0，每一步的波动就被限制在 IV 隐含的范围内。这样中位交易时段仍然贴近你的数据，尾部则与期权市场真正定价的水平一致。

<figure>
  <img src="figures/zh/fig08_fan_cap.png" alt="有无 ATM-IV 上限的 SPX 路径扇形">
  <figcaption><b>图 8.</b> SPX 百分位扇形（p0…p95）。左：无上限，被解开的 GARCH 棘轮把最差路径推进 −50% 保护带（p5 已 −5.2%）。右：`atm_iv = 16.5%` 时扇形与市场一致，p0 −4.4%、p5 −1.8%、p95 +1.8%。中位数（±1.3%）不变，只修掉了病态尾部。p0 是单条最差路径。</figcaption>
</figure>

> ATM-IV 锚在这里起到关键的调和作用：一边是平静的实现波动率（本例年化 6.3%，约 0.4%/日），另一边是期权市场真正交易的隐含波动率（约 16.5%，对应 VIX 约 15）。没有它，扇形尾部只是近积分拟合的模型伪影，不是对市场的描述。

## 3. 模型二：SVI 微笑

期权不是按单一波动率定价的。IV 随 moneyness 变化：put 侧更贵（负偏度），ATM 附近浅降，深虚值 call 略升。模拟器用 SVI（Stochastic Volatility Inspired）参数化来捕捉这一点，自变量为对数 moneyness `m = ln(K/S)`：

```
IV(m) = a + b·( ρ·(m − m₀) + √((m − m₀)² + σ²) )
```

`a` 为水平，`b` 为翼部陡峭度，`ρ` 为偏度（负值即 put 偏度），`m₀` 为顶点，`σ` 为曲率宽度。

### 3.1 为什么用 SVI 取代旧二次型

旧的二次拟合 `IV(m) = c₀ + c₁·m + c₂·m²` 在观测到的 ±5–6% moneyness 带内没问题，但模拟器要把 put 定价到 ±15%（`ladder_range_pct`），也就是说微笑得靠外推。抛物线在翼部会冲过 100% IV，产生的 credit 在套利上不成立。SVI 带平方根项，翼部近似线性增长，因此保持有界。

<figure>
  <img src="figures/zh/fig05_svi_vs_quadratic.png" alt="SVI 与旧二次微笑">
  <figcaption><b>图 5.</b> SVI（蓝）对比旧二次型（虚线），二者拟合于同一 ±6% put 带并外推。越过模拟阶梯（±15%，阴影区）二次型冲过 100% IV，SVI 则保持有界且单调。阴影的 ±15% 是模拟器实际定价的区域。</figcaption>
</figure>

### 3.2 拟合与守卫

`(a, b, ρ, m₀, σ)` 拟合实盘链的 put IV，初值有多组（确定性的二次种子加翼部斜率估计）。守卫包络作为约束直接写进优化（SLSQP）。对真实 0DTE 链来说这一点是决定性的：链的偏斜极陡，无约束最优解会落在 `b` 的上界、σ → 0，翼部远超上限，结果每个种子都被丢弃，捕获直接失败，尽管一个可用的有界解明明存在。现在守卫只对结果做断言；仍然不满足的拟合才回退到默认快照，并报出是哪个守卫拒绝的。

| 守卫 | 目的 |
|---|---|
| `SVI_WING_CAP = 1.0`、下限 `0.005` | `[−15%, +15%]` 内不允许 >100% IV、不允许非有限值 |
| put 翼在 `[−15%, 0]` 上单调 | 不出现蝴蝶 / 垂直套利翻转 |
| `±30%` 外不允许负 IV | 外推合理性 |
| put 偏斜 ≥ `SVI_MIN_PUT_SKEW`（1 个 vol 点） | 拒绝平坦、无信息的微笑 |
| RMSE 在链的 `1.4826 × MAD` 之内 | 拒绝只拟合了部分链的结果。用稳健尺度，单个野报价无法抬高基线来放行坏拟合 |

IV(m) 关于 m 是凸的，所以包络可以坍缩成几个标量不等式：两个端点上限、夹进宽区间后的顶点处最小值、以及 m = 0 处的翼部斜率符号。求解器可以直接满足这些条件。

实盘 0DTE 链里大部分是"无 vega"报价：远虚 put 没有买价（ask 钉在 0.05 跳动上）；有些档位的 mid 卡在最小跳动上（十几个 strike 价格恒为 0.075，造出凸 SVI 拟合不了的假 IV 驼峰）；深度实值 put 的 mid 又几乎等于内在价值。`smile_capture_points` 在拟合之前把这些点剔除（要求买价至少两个跳动即 `0.10`，且 `0.005 ≤ |Δ| ≤ 0.75`），并用链快照自己的 spot 做 moneyness 映射，保证 `m` 与 IV 描述的是同一时刻。

快照的来源依次是：IB 行情缓存可用时取实盘链捕获（`config/sim_smile.json`），否则用内置默认（`config/sim_smile_default.json`，ATM IV 约 20%），再否则用内置常量。当前用的是捕获还是默认，会在标定面板中显示。

## 4. 模型三：BSM 定价与价差

0DTE SPXW 在 16:00 ET 收盘结算。每张合约都是 0DTE put，到期时间逐 bar 衰减 `T_t = (steps−1−t) · bar_seconds/(252·6.5h)`。价值用 Black–Scholes 计算，与实盘 `gex_calculator` 属于同一套数学：

```
d1 = [ln(S/K) + (r + ½σ²)·T] / (σ√T),  d2 = d1 − σ√T
put = K·e^{−rT}·Φ(−d2) − S·Φ(−d1)
```

<figure>
  <img src="figures/zh/fig10_bsm.png" alt="BSM put 价值与 delta">
  <figcaption><b>图 10.</b> 阶梯上的 BSM put 价格与 delta。delta 驱动入场 `short_delta` 带；价格曲线驱动 credit。阶梯是以入场现货 ±15% 为界的固定 5 点网格。</figcaption>
</figure>

*mid* 为 `put(S,K,T,σ_iv)`。入场成交遵循一套保守规则：绝不优于自然价，并按 tick 取整，`fill = min(向下取整到tick(mid), S_bid − L_ask)`，下限一格。合成的 bid/ask 为 mid ± ½ · `half_spread(m)`，半价差随 moneyness 变宽（`0.05·(1 + 8|m|)`）。

## 5. 路径依赖的微笑动力学

这一节是让世界对路径做出响应的部分。微笑不是固定的，它随每条模拟路径自身的波动率状态移动。所有动力学都收敛到一个值对象（`SmileDynamics`），逐 bar `t` 求值：

```
IV_t(m) = clip( base(m) + level_t + tilt_t ,  0.01, 5.0 )
```

- `base(m)`：已捕获的 SVI 快照。
- `level_t`：随路径波动率状态整体伸缩曲线。
- `tilt_t`：随路径波动率状态倾斜曲线，波动冲击时 put 侧变贵。

三条通道正交，可以独立调节。每条的默认值都是中性的，能逐比特复现旧公式（由固定的回归链验证）。

### 5.1 波动率水平联动（旧 λ）

最早的通道：`level = vol_beta · (σ_path − σ₀)`，随路径的单 bar sigma 线性平移整条微笑。`vol_beta` 默认 0.75，取 0 就是静态微笑。这条通道只做细微调整，水平主要还是来自快照。

### 5.2 偏度倾斜（σ 驱动，带到期放大）

`skew_beta > 0` 时，路径的 GARCH sigma 一旦偏离标定均值，IV 曲线就发生倾斜：put 翼变贵，call 翼变便宜，ATM 不动。`skew_t_gamma`（0..1，文献常见值约 0.4）用 `(T₀/T)^γ` 在临近到期时放大这种倾斜：

```
tilt_t = −skew_beta · (t_scale_t)^{skew_t_gamma} · clamp(σ/σ₀ − 1, −1, +3) · m
t_scale_t = T₀ / max(T_t, ½·bar)
```

波动率比值截断在 `[−1, +3]`，避免未收敛的尾部把翼部抛到离谱的区间。整套是闭式的，运行期不会重新拟合 SVI。

<figure>
  <img src="figures/zh/fig06_smile_tilt.png" alt="路径依赖的偏度倾斜">
  <figcaption><b>图 6.</b> 晚期 bar（t_scale 放大）的倾斜：路径波动率越高（深色）put 翼越贵、call 翼越便宜；ATM 被钉在锚点（约 20%）。年化标签用的是数据实现波动率（6.3%）；倾斜移动的是偏度形状，不是水平。</figcaption>

### 5.3 方差预算 ATM 锚

`atm_budget = true` 时用闭式的 GJR 条件期望取代平坦水平：每根 bar 的 ATM IV 重新锚定到模型在给定路径 sigma 状态下的年化剩余期望方差，加权日内 U 型，并做归一化，使第一根 bar 与已捕获快照完全一致：

```
p_eff = α + γ·γ_mult/2 + β                    （持久性；/2 来自 E[1[ε<0]·ε²] = ε²/2）
v̄    = ω / (1 − p_eff)                         （无条件方差）
u2_k  = u(k)² · bar_frac
S(t) = Σ_{k>t} u2_k ,  P(t) = Σ_{k>t} p_eff^{k−t} · u2_k
A(t) = v̄·(S(t) − P(t)) ,  B(t) = P(t)
σ²_t = v̄ + budget_beta·(σ²_path − v̄)
v_t  = A(t) + B(t)·σ²_t
level = iv₀·(√(v_t/v₀ · t_scale_t) − 1)   ,  v₀ = v̄·S(0)
```

此时平静路径会呈现出模型的日内 IV 剖面：早段烧掉，临近收盘渐进抬升，谷底的深度和时点跟随收盘桶权重。旧公式给的是平坦水平。

<figure>
  <img src="figures/zh/fig07_budget_level.png" alt="方差预算 ATM 锚水平">
  <figcaption><b>图 7.</b> 全天的 ATM IV。旧的 level（灰虚线）平坦。预算锚（蓝，平静态 σ=√v̄）午间烧到约 15%，临近收盘又抬回锚点；压力态（橙，1.5·√v̄）全程更贵，并向上进入到期。`budget_beta` 是控制锚对 GARCH 状态追踪多强的 A/B 旋钮。</figcaption>
</figure>

> 锚是理论值：剩余方差随持久的 GARCH 状态缩放，因此比线性的 `vol_beta` 联动强不少。真实平静日的尾盘 IV 之所以低于模型期望，是因为方差风险溢价被烧掉，这一点当作已知残差接受，建模中没有处理。

### 5.4 VIX 映射

这里没有模拟的 VIX 过程。`volatility` 入场条件测的是一个代理：`VIX_t = clip(VIX₀ · σ_path,t / σ₀, 5, 100)`，其中 σ₀ 是标定得到的平均单 bar 波动率，VIX₀ 是对应的 VIX 均值（有数据时取最近 20 根收盘，否则用 20.0）。`volatility` 条件读的一直是这个代理，从不读真实 VIX 指数。

### 5.5 验证方法论

动力学是闭式且分门控的，验证用的是固定的逐比特链：中性旋钮（`skew_beta = skew_t_gamma = 0`、`atm_budget = false`）下，每个输出都必须用 `np.array_equal`（不是 `allclose`）匹配已提交的基线。链条是 `legacy → A → AB → ABC`，每个门控测试都要求：把某条通道关掉能精确复现上一阶段，且上一阶段输出与它的 `.npz` 逐字节一致。这样加一个旋钮就不会静默改变旧运行依赖的行为。

## 6. 风险分析与实验面

每个单元格的有效载荷（`sim_risk.py`）计算这些东西：

- 当日 PnL 分布：均值、中位数、σ、胜率、CVaR₅ / CVaR₁、最差日。
- 出场原因分解：到期 / 止损 / 止盈 / 从未入场。
- 日内最大回撤：每条试验的逐分钟 MTM 序列。
- 自助法权益曲线：把当日 PnL 抽样拼成 `bootstrap_len` 天的序列，得到最大回撤分布与爆仓概率 `P(最大回撤 ≥ 阈值)`，阈值取账户权益的一个比例（默认 20%）。

实验面有三类：止损倍数扫描；固定短腿距离对比动态短腿距离（`dynamic_k`）；以及一组压力旋钮（ν、γ×、λ/σ、skew β、t^γ、budget），用来跟基线做 A/B。报告另外还会输出 SPX 百分位扇形（图 8，这是市场模拟本身的属性，各扫描行完全相同）和价差 MTM 分位扇形。

## 7. 局限

- 隐含波动率和现实波动率是脱节的。期权按微笑快照的 IV 定价（默认 ATM 约 20%），现货却按数据的实现波动率运动（此处 6.3%）。平静的 CSV 配上偏高的微笑，会让处在 2–2.5% 虚值的 deep-OTM short put 很难被触及，胜率接近 100%。这反映的是两个波动率世界的错配，不是策略本身有优势。缓解办法：捕获实盘微笑、用更贴近现实的数据、相对地读扫描行、并设置 ATM-IV 锚。
- 止损在 bar 收盘时检查。盘中击穿又回拉的走势在 1m 上看不到；用更细的 bar（CSV 5s）能缩小这块盲区。
- 每个策略每天只入场一次。除 family 子策略触发外不支持再入场；family 模式下不支持 SL/k 扫描。
- `trend`、pmove、RSI、`atm_iv` 这几类门槛没有实现。启用任意一个都会被拒绝，而不是给出错误的模拟结果。
- 非 `bull_put` 策略（如 `bear_call`）一律拒绝。
- `state.vix` 是代理，不是 VIX 过程；`volatility` 条件测的就是它。
